# System Architecture

## Overview
This application is built using Next.js 14 and React 19, demonstrating modern full-stack web capabilities.

## Tech Stack
- Frontend: React, Next.js, TailwindCSS
- UX Components: Shadcn UI, Radix UI

## Key Features
- Server-side rendering (SSR) for fast initial loads
- Component-driven architecture
- Responsive web design using Tailwind
